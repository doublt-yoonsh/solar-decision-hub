# Solar Decision Hub — 발표 자료

> 발표/제출용 핵심 슬라이드. 슬라이드 하나당 한 섹션.

---

## Slide 1 — 문제 정의

### RPS 폐지 충격, 한국 PV 사업자에게 무엇이 닥치는가

- **2027년 RPS 폐지** 예정 → 신규 REC 발급 종료
- 현재 약 5,000+개 사업자가 SMP+REC 현물 시장에 노출
- REC 가격은 2024 평균 80,000원/REC → 사업자 매출의 30~50%
- **공백**: 시장 전환을 어떻게 해야 할지 비교할 도구가 없음
  - 정부 발표는 정책 단위, 개별 사업자 시뮬레이션 부재
  - EPC가 제공하는 사업성 검토는 자사 솔루션 영업 목적
  - 컨설턴트 견적은 건당 수백만원

> **사업자가 1분 안에 자기 발전소의 4가지 미래를 비교할 수 있어야 한다.**

## Slide 2 — 솔루션

### 좌표 하나로 3가지 분석 동시 제공

```
좌표 입력
   ↓
자동 매핑: 주소 / 일사량 / 부지유형 / 변전소
   ↓
┌─────────────┬─────────────┬─────────────┐
│  진단        │  시나리오    │  리스크      │
│  벤치마킹    │  4 비교      │  포트폴리오  │
└─────────────┴─────────────┴─────────────┘
   ↓
추천 시나리오 + NPV + 정책 리스크 점수
```

### 4가지 시나리오

| ID | 이름 | 핵심 |
|---|---|---|
| A | 현물시장 (SMP+REC) | RPS 폐지 후 REC 0 가정 — 변동성 큼 |
| B | 고정가격계약 (20년) | 입찰 통과 시 안정적 — 진입 경쟁 |
| C | 2027 신규입찰 | 정책 미확정 — 추정값 조정 가능 |
| D | 직접 PPA | RE100 협상 — 단가/계약기간 자유도 |

각 시나리오에 대해 **NPV / IRR / 회수기간 / 민감도(tornado)** 자동 계산.

## Slide 3 — 기술적 도전

### 1. 외부 API 없이 작동하는 좌표 인리치

```
카카오 키 미발급 / VWorld 영구 제외 → 자체 휴리스틱
```

- **좌표 → 주소**: mock fixture 5개 (실키 등록 후 실제 모드 자동 전환)
- **부지 종류**: 5개 휴리스틱 규칙 (산/저수지/도로명+건물/전·답/디폴트), 단위 테스트 7개
- **변전소 매칭**: Haversine 50km 내 최근접, 초과 시 권역 평균 폴백
- **일사량**: 위도 기반 선형 추정 (33°N → 4.2 PSH, 38°N → 3.5 PSH)

### 2. 4-시나리오 시뮬레이터 (시드 고정 Monte Carlo)

- 시나리오 A: SMP ±15% 변동성 1,000회 → percentile NPV 분포
- 시나리오 B: smpBaseValue/recValue 분해 + 사용자가중치 보정
- 시나리오 C: 정책리스크 계수 (0~1) × 단가
- 시나리오 D: PPA + RE100 premium − 송배전 이용료
- **시드 고정** (mulberry32) → 동일 입력 시 동일 결과 (재현성)

### 3. 정책 리스크 분해 (PolicyRiskBreakdown)

```
totalScore = scenarioAExposure × 30  (REC 폐지 영향)
           + scenarioCExposure × 40  (정책 미확정)
           + sunsetTimingRisk  × 30  (sunset±5y 신설 비중)
```

분해 결과는 결과 카드 + PDF 부록에 일관 노출.

### 4. 번들 최적화 (Recharts + @react-pdf 분리)

- /result First Load JS: **728kB → 128kB** (-82%)
- Recharts 차트는 dynamic import + Skeleton
- PDF는 click-to-mount (사용자 클릭 시점에 다운로드 시작)

## Slide 4 — 데모 흐름

### 첫 사용자: 데모로 5초 진입

```
랜딩 → "소규모 (99kW 영광)" 클릭
    ↓ (자동 채움)
결과 대시보드 즉시 표시
  - 진단: 동급 상위 23%
  - 추천 시나리오: B (NPV 4.2억)
  - 정책 리스크: 45/100
```

### 운영 사업자: 5단계 위저드 직접 입력

```
1. 사용자 타입 (신규/운영중/다수)
2. 위치 좌표 → 자동 매핑 + 출처 배지 (mock/real/fallback)
3. 발전소 정보 (용량 슬라이더 + 부지 + 가중치)
4. 운영 정보 (선택)
5. 재무 가정 (CAPEX + PR + 할인율 슬라이더)
   ↓
결과 → PDF 다운로드 → 가정 확인
```

모든 입력은 **localStorage 자동 저장** — 새로고침 후 복원.

## Slide 6 — 비즈니스 적용 가능성

### Layer 1: 단독 무료 도구

- 한국 PV 시장에 공개 추정 도구 부재 → 즉시 활용 가능
- 사업자 1분 진단 → 컨설팅 수요 검증 funnel

### Layer 2: SaaS 모듈 임베드

대상 플랫폼:
- **EPC 영업 도구**: 견적과 함께 시나리오 비교 제공 → 영업력 강화
- **RE100 중개 플랫폼**: 사업자 측에 PPA 단가 자동 비교
- **PV 통합관리 SaaS**: 운영 데이터 + 시나리오 분석 결합 → 차별화

이 도구는 **로직과 시각화 자체가 자산** — API 또는 Embed iframe 형태로 제공 가능.

### Layer 3: 유료 정밀화

- 일별 SMP/REC 실시간 데이터 + Monte Carlo
- 발전소별 실측 캘리브레이션
- 컨설팅 수준 PDF 리포트
- B2B 라이센스 (월 고정 + 사업자별 호출량 과금)

## Slide 7 — 기술 차별점 요약

| 영역 | 일반적 접근 | 본 프로젝트 |
|---|---|---|
| 데이터 | 외부 API 의존 → 키 발급 / 도메인 등록 필요 | **정적 JSON 시드 + mock-first** → 즉시 작동 |
| 추정 | 단일 시나리오 + 평균값 | **4 시나리오 + Monte Carlo + 시드 고정 재현성** |
| UI | 데스크톱 위주 | **모바일 우선 + sticky 진행바 + 5초 데모** |
| 출처 표기 | 결과만 표시 | **모든 추정값에 source/credibility 배지 일관 노출** |
| 번들 | 단일 청크 | **차트/PDF 분리 — /result 128kB** |
| 테스트 | 부재 | **111 unit tests + 도메인 sanity range 검증** |

## 부록: 도메인 sanity 검증 결과

| 케이스 | 항목 | 사용자 예상 | 우리 계산 |
|---|---|---|---|
| 99kW 영광 | 연 발전량 | 130~145 MWh | ~133 MWh ✓ |
| 99kW 영광 | A 첫해 매출 | 1,500~2,500만 | ~2,830만 (+13%, 12m trailing 기반) |
| 3MW 경주 | A 첫해 매출 | 4억~7억 | ~8억 (통합 test 4억<x<9억 통과) |
| 500kW 당진 | 4 시나리오 NPV 양수 | yes | ✓ all positive |

차이는 시드 데이터(2025년 SMP/REC 12개월 trailing이 사용자 보수 가정보다 낙관적)에서 발생. 사용자가 PR/할인율 슬라이더로 즉시 보정 가능.
